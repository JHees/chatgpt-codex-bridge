# 后台协作与用户设置：新增需求边界

> 当前状态更新：后台三操作、配置、设置／任务控件和随包脚本已接入开发候选入口，非 Pro Medium 后台两轮及删除已实测。完整模型组合与 UI 实机验收尚未完成。请以 [最新验收门槛](BACKGROUND_IMPLEMENTATION_GATE.md) 和 [使用说明](USAGE.md) 为准。下文保留早期需求与调研记录，不再作为当前实现状态；尤其“永久拒绝 Pro”和前台收发不是新方案。

本文区分已实现的单包分发与仍待完成的后台协作需求。**后台收发、自动删会话和 Bridge 自有设置页尚未实现**。

最新入口验证见 [按任务后台协作：第一阶段入口验证](BACKGROUND_IMPLEMENTATION_GATE.md)。当前已通过 App 自有客户端只读取得 Chat 模型目录，但后台发送/删除及自动提交尚未通过实机验收。后续需求已扩展为设置默认值、当前任务输入区开关与模型选择，以及 Chat 规划指挥/Codex 执行回报；不能将下面的早期建议视为全部交付范围。

## 用户期望

- 收发 Chat 全程不切换当前任务、页面、焦点或输入框。
- 在同一专用会话内完成多轮协作；明确结束且不保留时自动删除。
- Bridge 有自己的 Loader 设置页，可配置行为；安装 Bridge 时自动提供 skill，无需第二次安装。

## 调研事实

- Loader `PLUGIN_SPEC.md` 已支持 `api.settings.registerPage` 和插件作用域的 `api.storage`，设置页本身不需要新增 Loader 业务接口。
- 本次经跨仓库授权后，Loader 新增 schema-v2 包内 `agentSkill` 声明及统一生命周期；不向 renderer 开放任意文件写入。Bridge 已改为一个包含 skill 的 ZIP，不再分发第二个 Codex 插件包。源码测试已通过，当前运行副本未部署，见 [VALIDATION.md](VALIDATION.md)。
- 当前 Bridge 通过新建 Chat、composer 和可信 Enter 收发，必然影响页面，不满足后台要求。
- 对当前安装 App 的只读源码检查找到了内部 Chat conversation client，包含流式发送、读取和删除能力，以及 App 自有后台任务发送分发逻辑。**尚未证明这些内部能力能通过稳定、可复用的插件入口完整调用**。存在不代表可以据此承诺后台验收通过。

## 建议实现

### 后台收发

将收发适配器替换为 App 已有的 Chat 客户端或后台操作入口，保留严格协议、单调用、幂等和一次修复规则。必须先验证创建、Medium/High 参数、响应结束事件和会话 ID，再接入生产逻辑。不得自己抽取登录凭据、直接写 SQLite 或在后台失败时偷偷回退到页面点击。未支持的 App 版本返回明确的不可用状态。

### 会话复用和删除

一个 Bridge session 内自然复用同一 Chat；每轮回复后不立即删除。`finish` 表达“不再使用”，默认删除该 session 确认拥有的 Chat。设置可选“结束后保留”。只删除 Bridge 创建且所有权可核对的会话，不从侧栏名称猜测、不批量清理用户 Chat。删除失败返回明确状态并保留准确 ID，不伪装成已清理。

### 设置页

页面提供运行/兼容性状态、Medium/High、结束后删除/保留、等待时限。skill 已由 Loader 插件管理页随安装管理，Bridge 设置页不再另做一套安装器。不能把未完成的后台能力做成可启用的假开关。设置改变在下一 session 生效，避免正在发送的请求被改变。

### skill 安装（本次已实现，待运行部署验收）

用户在 Loader 中预览并确认一个 Bridge ZIP。Loader 将 renderer 与 skill 放入同一包目录，并在当前用户 `.agents/skills` 下创建受管理的目录联接。更新只替换一个包；失败回滚也同时恢复 skill。禁用和移除只清除受管理的入口，保留包内来源及用户自己的同名内容；冲突时提示，不覆盖。旧版单独安装的 Codex 插件仍需用户在原管理入口移除一次，不进行无授权清理。

这部分使用通用声明，不包含 Bridge 专用 Loader 接口。两个仓库既有版本和未提交改动均保留；Loader 原生二进制必须重新构建并安装，不能用插件热重载补齐该能力。

## 验收标准

发送和读取期间当前任务、路由、焦点、草稿及滚动位置不变；连续两轮返回结构化结果；只删除本次专用 Chat；保留模式能继续复用；设置保存、取消与热重载无重复节点；skill 安装能检测冲突且不会覆盖用户修改；后台入口不适配时完全不触发前台发送。
