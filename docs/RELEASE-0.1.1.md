# Bridge 0.1.1

## 本次更新

- 使用 App 自有 Chat 客户端后台规划与交流，不切换前台页面，不改变 Codex 执行模型。
- 设置页自动保存默认值；输入区提供任务开关、模型和思考程度的级联选择，设置入口跳转系统设置页。
- 一个 ZIP 同时安装、更新 renderer 与 bridge-chat skill。
- 同次协作复用 Chat，按策略结束并删除或保留；只清理可核对归属的会话。
- 短窗口续读与总等待期限分离，同 turn 不重发；只读状态可恢复当前实例中已校验的回复。
- 完整说明动作协议，返回具体修复原因；兼容研究类动作同义词、单个 JSON 代码块或纯 JSON，以及冗余的 response 类型字段。身份、预算、权限与动作结果关联仍然校验。

## 验收范围

用户已确认本机候选可用。实际完成 Sol「中」规划、Luna 执行的三轮资料调研：查询来源、回报证据、追加核验、Chat 确认及原任务最终交付。成功及此前失败的 Chat 均保留，未使用 Pro。

本地检查包含类型检查、lint、133 项测试、构建及 ZIP/校验和验证。标签 CI 必须再次检查成功才公开 Release。

这不代表 Spark、Pro、完整编码与失败修复、真实 15 分钟慢回复或全部输入方式已经验收。详细证据与历史限制见 [VALIDATION.md](VALIDATION.md)。

## Loader 兼容性

需要原生 Windows Loader 的 schema-v2 随包 skill、host commands、设置存储与页面导航、输入区控件、可编辑可见上下文及原生提交回执接口。

最低要求为原生 Windows Loader **0.5.11**；该版本包含此前在 0.5.10 本机候选上实测的接口补丁。Loader 与 Bridge 分别构建、测试和发布，请先更新 Loader，再更新 Bridge。运行 Bridge 诊断核对 App 适配，缺少接口时暂停协作；Bridge 插件不自行升级宿主。

## 安装与更新

在兼容 Loader 中使用仓库 GitHub 地址安装，或下载 Release 的 `bridge-0.1.1.zip`，不要安装 GitHub 自动生成的源码 ZIP。校验文件为 `bridge-0.1.1.zip.sha256`。

已有插件可通过 Loader 检查更新。候选包含本地修改或更新增加权限时可能需要确认；不会绕过该提示。重载重置内存中的任务选择及 session，不会恢复、重发或清扫历史 Chat。更新前先结束活动协作。
