# Bridge 0.1.3

本版本将已热加载测试并确认发布的体验改动整理为正式自动更新包。一个 ZIP 同时包含 renderer 与随包 skill。完整折叠和双向移除联动需要原生 Windows Loader 0.5.12 或更新版本；请先更新 Loader，再更新 Bridge。发布不会替用户安装或重启程序。

## 改动

- 输入区协作说明默认收起，摘要显示「Chat 协作 · 模型 · 思考程度」；旧草稿保留原来的模型摘要。隐藏区域的光标定位由 Loader 的通用输入区接口处理。
- 用户发送的消息中，独立完整的协作说明可以展开和收起，保留用户正文及原生消息数据。
- 点击 Loader 的说明移除按钮会立即关闭当前任务协作；关闭协作也会清除说明，包括完整且未改动的恢复草稿说明。Loader 代管控件通过通用通知接入，插件自有开关不重复通知。
- 等待窗口与结束策略使用紧凑菜单，自动保存；结束策略支持删除、归档、保留。
- 用户主动结束与任务成功完成分开：结束可中断本地等待，不再因读取占用返回 `CALL_BUSY`，不取消原生生成，也不继续交付迟到动作。
- 删除和归档仍检查准确归属、用户介入和生成状态。归档需要原生状态确认，不会降级为删除；仅说“结束”时随包 skill 默认保留会话。

## 验证与兼容性

Bridge 完整检查包括类型检查、lint、163 项回归测试、renderer 构建和独立 ZIP 校验。真实输入框验证了「移除 → 关闭协作」和「关闭协作 → 清除说明」，原草稿保持不变，测试没有发送消息或创建 Chat。候选热加载后的插件运行和随包 skill 链接检查通过。

归档、并发结束和失败恢复使用受控客户端回归验证；本轮未重新执行真实归档或 Pro 生成测试。不同模型组合的历史验证范围保持不变，详见 [体验验证记录](UX-ITERATION.md)。Loader 0.5.11 仅提供基础接口，不具备完整折叠与反向通知能力。

自动更新附件为 `bridge-0.1.3.zip` 及同名 `.sha256`。更新权限和来源不变；若 Loader 检测到本地修改，仍按正常流程要求确认。
