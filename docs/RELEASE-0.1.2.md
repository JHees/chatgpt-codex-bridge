# Bridge 0.1.2

本版本按用户要求提供给 Loader 自动更新测试。一个 ZIP 同时包含 renderer 与随包 skill；发布流程不会直接更新用户的运行副本。需要原生 Windows Loader 0.5.11 或更高版本。现有本地修改可能触发 Loader 更新确认。

## 改动

- 按 host/task 保存协作开关、模型和等待偏好，重载后恢复；全局默认值不覆盖已有任务。活动 Chat 和消息不持久化。
- 输入区改为简短、可编辑的 skill 引用及配置标识，详细规则留在随包 skill。
- Chat 简报与回复使用自然语言，首行状态区分继续、需要确认和建议完成；保留旧 JSON 回复兼容与本地结构化调用。
- 核对完整回复与归属后，为专用 Chat 的原标题添加 `[bridge] `；重复前缀、改名干预和更新错误分别处理。
- 本地完成报告得到 Chat 确认后，插件自动删除或保留会话。清理失败保留准确目标和错误原因；最后一份自动完成回执可用于输出丢失恢复。
- 同步更新随包 skill、使用说明、架构与安全文档。

## 验证与限制

完整检查包含类型检查、lint、143 项测试、renderer 构建和单包 ZIP 校验。包内同时包含 renderer 与 skill。最低 Loader 要求仍为 0.5.11，本次未修改 Loader。

尚未实现完全免上下文的插件自主调度，仍采用短可见说明。无协作回执的关闭草稿，其临时模型覆盖值还不能可靠迁移至正式任务；关闭状态安全保持。

自然语言真实模型闭环、标题显示和自动删除仍需运行候选验收。没有进行新的 Chat 或 Pro 生成测试，也不以旧版验收替代本版本结果。详见 [验收边界](UX-CANDIDATE.md)。
