# Bridge 0.1.4

修复 Codex 更新后后台 Chat 显示 `APP_UNSUPPORTED`、无法读取模型目录的问题。新版 Codex 将原来的独立 Chat 客户端拆入主程序资源，Bridge 现在按原生服务关系识别流处理客户端、认证请求客户端和标准化模型查询，继续兼容旧版独立客户端。

## 改动

- 从已引用的 App 主程序资源中解析导出映射，不固定文件哈希或压缩后的变量名，也不执行资源源码文本。
- 复用原生模型查询与流回调，将会话读取、流状态、改名、归档和删除映射到对应的原生请求接口。
- 保留资源大小和搜索范围限制；服务缺失或存在多个不一致实例时仍报告不可用。客户端实例被替换后不会继续认为缓存连接有效。
- 插件权限、Loader 接口、随包 skill 和独立更新源保持不变，完整体验仍需要原生 Windows Loader 0.5.12 或更新版本。

## 验证范围

类型检查、lint、15 个测试文件中的 167 项测试、renderer 构建与独立 ZIP 校验通过。新增回归覆盖新版打包布局、原生模型查询、流回调和请求参数映射、缺失/歧义服务，以及客户端实例替换。

在 Codex 26.908.4834.0 的已加载候选中，后台连接恢复、模型目录返回 6 个可用选项，输入区接口与随包 skill 正常。此次没有发起 Chat 消息；新版真实消息往返、改名及结束清理仍未实测。此前版本的真实协作记录保留为历史证据，不扩展为此次修复的实机验收。

目标更新附件为 `bridge-0.1.4.zip` 与 `bridge-0.1.4.zip.sha256`。本地提交和打包不会创建 GitHub Release，也不会自动替换已安装候选。
